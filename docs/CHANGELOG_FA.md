# تغییرات مهم

## آبان ۱۴۰۵ (نوامبر ۲۰۲۶)

### اپ‌ها
- **نسخه‌ی تلویزیون:** همان APK روی Android TV؛ بنر، کنترل با ریموت، ستون وسط صفحه، برنامه‌های تلویزیون در «خارج از VPN».
- **اشتراک هات‌اسپات** در اپ اندروید، با راهنمای جدا برای ویندوز، اندروید، آیفون، مک و تلگرام.
- **انتخاب همه** در برنامه‌های خارج از VPN (اندروید و ویندوز).
- **اپ ویندوز:** برنامه‌های خارج از VPN، کارت حساب با پروفایل و حجم.
- **وصله‌های کوچک:** bsdiff؛ مثلاً ۶٫۸ مگابایت به جای ۷۹. اپ حجم واقعی دانلود را نشان می‌دهد.
- **کانال آزمایشی:** اول یوزرهای تست، بعد همه.
- رفع «وصل است ولی دیتا نمی‌دهد» (بستن درست TUN)؛ برگشت به رفتار اتصال قبل از نسخه‌ی ۸۰.

### سرورها
- **تانل پشتیبان SSTP:** اگر GRE قطع شد، ترافیک SSTP خودکار از AmneziaWG به سرور لینوکس می‌رود.
- **مصرف به تفکیک سرور و پروتکل:** pv-agent برای هر پروتکل یک نشست حسابداری می‌فرستد.
- **سایت پوششی** جدید روی سرورهای لینوکس.
- umstatus سریع‌تر (کش)، انتشار فقط فایل‌های لازم.

### ابزارها
- **Persian Admin:** همه‌ی کارهای ابزار انتشار روی گوشی؛ انتقال تنظیمات از ویندوز با یک فایل رمزدار؛ ظاهر جدید.
- **امکانات جدید:** گرفتن فقط کدهای عوض‌شده بدون دانلود دوباره‌ی برنامه.
- ابزار نسخه‌ی ویندوز را خودش از GitHub می‌گیرد.
- صبر خودکار وقتی انتشار قبلی وسط کار قطع شده.

### بات ریسلر (مخزن جدا)
- **بدهی ریسلرها:** شارژ نسیه یا نقدی، ثبت پرداخت، تنظیم بدهی، صورت‌حساب بدهی.
- حساب شارژهای هر ریسلر؛ علت شکست سفارش‌ها؛ برداشتن پروفایل‌های خراب.
- گزارش مصرف سرورها.
