# اپ VPN (SSTP و چندپروتکلی)

اپلیکیشن اندروید (iOS در آینده) با رابط فارسی که به MikroTik کاربر با SSTP وصل می‌شود و حجم و روزهای باقی‌مانده را از User Manager نشان می‌دهد. در حال گسترش به چند پروتکل و چند سرور.

## وضعیت
- اپ اندروید ساخته شده و اتصال SSTP موفق است
- نمایش حجم و روز باقی‌مانده صحیح و هماهنگ با ربات تلگرام
- بیلد خودکار با GitHub Actions

## امکانات
- اتصال SSTP به MikroTik
- نمایش حجم و روزهای باقی‌مانده (سرویس lookup در یک container روی خود MikroTik)
- **تنظیمات از راه دور:** اپ تنظیمات سرور را از فایل config امضاشده روی روتر می‌خواند
- **پشتیبان دستی:** وارد کردن فایل config امضاشده (مثلاً از تلگرام) وقتی سرور قبلی در دسترس نیست
- **آپدیت داخل برنامه:** دانلود APK از روتر
- **Split tunneling:** امکان خارج کردن برنامه‌ها از VPN (مثل اپ‌های بانکی)

## نقشه راه
- افزودن پروتکل‌ها و سرورهای دیگر با موتورهای **Xray** و **sing-box**
- **تونل DNS** به‌عنوان حالت اضطراری
- SSTP آخرین اولویت؛ فقط وقتی بقیه شکست خوردند. بررسی سرورها/پروتکل‌ها باید سریع باشد
- User Manager میکروتیک تنها منبع کاربران، حجم و روزها برای همه سرورها
- یک سایت پوششی روی هر سرور جدید

## معماری
```
اپ اندروید
  ├─ config امضاشده ◄── روتر (یا فایل دستی)
  ├─ اتصال: [پروتکل‌های جدید ...] ──► fallback: SSTP ──► MikroTik
  ├─ حجم/روز ◄── container lookup روی MikroTik ◄── User Manager
  └─ آپدیت APK ◄── روتر
```

## نحوه کدنویسی
- امضای config برای جلوگیری از تنظیمات جعلی؛ کلید خصوصی امضا هرگز در ریپو نیست
- کلید امضای APK و هر secret فقط در GitHub Secrets
- رابط کاربری فارسی و راست‌به‌چپ

## بیلد
با هر push، GitHub Actions فایل APK را می‌سازد و در بخش Artifacts قرار می‌دهد.
